DIABETIC RETINOPATHY CLASSIFICATION
COMPARISON OF FOUR TRAINING APPROACHES


Dataset: APTOS Diabetic Retinopathy
Model: ResNet-18
Classes: 0 No DR | 1 Mild | 2 Moderate | 3 Severe | 4 PDR

Dataset split:
  Training   = 2563
  Validation = 549
  Test       = 550

Shared training setup:
  Batch size = 16
  Adam learning rate = 0.0001
  Epochs = 10
  WeightedRandomSampler
  Device = CPU


1. EXECUTIVE SUMMARY

Four approaches were tested:

  1. Baseline Cross-Entropy
  2. Focal Loss
  3. Weighted Cross-Entropy
  4. Ordinal Classification

Overall test results:

Model                         Accuracy   Precision   Recall    F1
------------------------------------------------------------------
Baseline Cross-Entropy        81.45%     0.8155      0.8145   0.8142
Focal Loss                    79.27%     0.7878      0.7927   0.7900
Weighted Cross-Entropy        82.00%     0.8137      0.8200   0.8155
Ordinal Classification       66.55%     0.7146      0.6655   0.6664

Weighted Cross-Entropy has the highest test accuracy and weighted F1.
However, its PDR recall is lower than the baseline.

The baseline has the highest PDR recall among the four models.
Weighted Cross-Entropy has the highest Severe recall.

The simple ordinal approach performs substantially worse overall,
especially for PDR.

IMPORTANT: These are academic ML results, not evidence of clinical
diagnostic suitability.

10. MODEL-BY-MODEL INTERPRETATION

BASELINE CE
------------
Strengths:
  - 81.45% test accuracy
  - 98% No DR recall
  - 55% PDR recall, highest among all four
  - Strong overall reference model

Weaknesses:
  - Severe recall only 45%
  - Mild and Severe remain difficult
  - Some high-severity cases are shifted downward


FOCAL LOSS
----------
Strengths:
  - 98% No DR recall
  - Designed to emphasize difficult examples

Weaknesses:
  - Accuracy drops to 79.27%
  - Severe recall drops to 41%
  - PDR recall drops to 48%
  - Macro F1 drops to 0.62

Conclusion:
  It did not solve the difficult-class problem.


WEIGHTED CE
-----------
Strengths:
  - Highest test accuracy: 82.00%
  - Highest weighted F1: 0.8155
  - Severe recall rises to 55%
  - Moderate recall rises to 81%
  - Severe -> Mild errors disappear

Weaknesses:
  - PDR recall falls to 41%
  - PDR cases shift more frequently toward Moderate/Severe

Conclusion:
  Strongest general-performing experiment so far, but the Severe/PDR
  trade-off requires further analysis.


ORDINAL
-------
Strengths:
  - Explicitly represents ordered severity
  - Many errors remain near the true severity

Weaknesses:
  - 66.55% test accuracy
  - 38% Severe recall
  - 2% PDR recall
  - Macro F1 = 0.44
  - High-severity cases collapse toward Moderate/Severe

Conclusion:
  The current simple BCE ordinal formulation is not competitive.

12. MAIN CONCLUSIONS

1. Standard Cross-Entropy is a strong baseline.

2. Focal Loss did not improve this experiment.

3. Weighted Cross-Entropy achieves the highest overall test accuracy
   (82.00%) and the highest Severe recall (55%).

4. The baseline achieves the highest PDR recall (55%).

5. Therefore, no single tested model currently maximizes both Severe
   and PDR recall.

6. The ordinal formulation is clearly weaker in its current form.

7. No DR detection is strong across all approaches. The difficult
   problem is distinguishing severity levels, especially Moderate,
   Severe, and PDR.

8. Accuracy alone is not sufficient to evaluate this project.

9. The next useful analysis is to measure the direction of errors:
   whether Severe/PDR cases are being pushed toward LOWER severity,
   HIGHER severity, or neighboring severity classes.

10. The next model decision should therefore be based on the
    confusion-matrix and severity-error analysis rather than simply
    choosing the model with the highest accuracy.
